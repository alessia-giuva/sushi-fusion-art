# 🍣 Sushi Fusion Art - Foggia

Benvenuti nella repository ufficiale di Sushi Fusion Art, un'esperienza culinaria premium nel cuore di Foggia. Questo sito web è stato progettato per riflettere l'eleganza e la qualità del nostro sushi fusion, combinando un design moderno "Dark & Gold" con una navigazione fluida.

## ✨ Caratteristiche Principali
- **Design Premium: Interfaccia raffinata in modalità scura con dettagli dorati.
- **Menu Digitale: Consultazione rapida di Nigiri, Uramaki, Pasta e Secondi.
- **Totalmente Responsive: Ottimizzato per smartphone, tablet e desktop.
- **Prenotazione Rapida: Integrazione diretta con WhatsApp per prenotare un tavolo con un clic.
- **Effetto Vetro (Backdrop Blur): Navbar moderna con effetto satinato.
